# Boss 工作台 v3

当前核定PBZ构建的本机隔离离线版。阿花、万钧、烟千岁、游龙四角色，共40项能力、41个绑定。

Insert工作台，↑↓选择，Enter确认，F6接管，F10恢复。烟千岁及游龙在游戏内选择。工作台为Windows键盘浮层；保留原生冷却、地形及每轮十分钟限制。

烟千岁保留900cm净空、24点、192次上限，仅初始化查询。新增落点中心与主角地面高差最多100cm；区域只接受不超过5度缓坡，平面残差和相邻采样高度突变不超过30cm，总高差不超过100cm。空间不足拒绝并保留当前角色。

不会修改正式游戏、正式存档或回写研究进度。使用根目录开始Boss工作台.cmd，详见70-四Boss工作台v3操作说明.md。
