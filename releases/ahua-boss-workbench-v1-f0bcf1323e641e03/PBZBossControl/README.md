# Boss 工作台与离线操控

提供新娘阿花（28项能力、29个技能绑定）和巨锤客：万钧（4项独立能力、4个技能绑定）。万钧采用自己的角色、配置与能力，不继承阿花的技能验收。阿花 v1 的完整历史验收与新工作台的版本验收分别保留，实际安装版本及验收范围以上级 `pbz-release.json` 为准。

## 开始使用

在现有项目根目录双击“开始Boss工作台.cmd”（原“开始阿花训练.cmd”也可），按窗口步骤准备隔离副本、核对研究Steam云同步关闭、启动研究游戏、进入场景并启用。请保留本项目现有Sandboxie环境、自编译加载器和Python运行时；此包供当前本机启动器安装使用。

如需重新安装，双击“管理阿花Mod.cmd”，选择本发布目录安装并启用。安装管理会逐文件校验；停用或卸载前须先结束研究会话。安装及卸载均保留个人键位和设置。

## 操作

F6接管、WASD移动、鼠标转向、F7切换可见敌对目标、F10恢复主角。Esc先恢复主角，再按一次打开原菜单。正常重载请在恢复后选择“系统→退出游戏→返回至开始界面”，再“继续游戏”；新场景就绪后自动装配，仍需F6主动接管。

## 游戏内 Boss 工作台

Insert 打开工作台，↑ / ↓ 选择，Enter 确认，Esc / Insert / F10 关闭。打开前先完整恢复主角，再压入独立的菜单输入层；关闭时撤除该层。选择其他已验收角色后，先回收旧装配，再建立新装配，需再次按 F6 接管。

可选择新娘阿花或巨锤客：万钧；列表显示各自的能力数量。琴女烟千岁、056_YouLong 保持“适配中”，不能接管；能力路径数量不代表可用技能数量。新增角色须有独立身份、授予、激活、结束、取消和恢复证据，不能通过编辑工作台列表开启。

工作台由配套只读状态层显示在研究游戏画面内，使用键盘操作，不接收鼠标；不是引擎原生 UMG 菜单。打开时拦截主角和技能输入，关闭后完整撤除输入层。切换不会重启游戏。

## 结束与支持范围

F10仅退出操控；结束整轮请点击启动器“结束本轮训练并核对正式存档”。每轮最多20分钟，每次装配最多10分钟；到时自动收尾。正式游戏和存档不安装加载器，研究进度不回写，也不自动回档。

仅支持当前核定PBZ构建和本机隔离启动器，不是任意电脑可用的便携包。程序SHA-256为`4415933ce33476f14c837abb61a1b60af8b78cd81783896501913a7aac69e423`，不匹配会拒绝装配。已验证溪谷局部地形；无合适同层落点或视线时拒绝生成，需由玩家移动至开阔地面站稳后再启用。

阿花三项配对抓取能力保持隔离，六项被动/工具保留原生授予。支持上述恢复后原菜单重载路径；直接OpenLevel诊断不作为玩法加载方式。跨版本、列表外Boss和所有关卡不在本版支持范围内。

本包不含游戏资源、存档、账号或临时会话凭据。版本、每个文件的SHA-256及不可变验收报告见上级目录`pbz-release.json`。
