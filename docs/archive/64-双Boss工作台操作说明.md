# 双 Boss 工作台操作说明

当前状态：双Boss工作台v1已完成终验、发布、安装启用及逐文件校验。版本为 `ahua-boss-workbench-v1-f0bcf1323e641e03`；发布记录与压缩包校验值见[交付说明](65-双Boss工作台v1交付说明.md)。

## 启动

双击根目录“开始Boss工作台.cmd”，按启动窗口的 1、2、3 步准备隔离副本、确认研究 Steam 云同步关闭、进入场景并站稳后启用。第 4 步结束本轮训练。训练结束会自动回收临时角色并核对正式文件。

这是本机当前核定 PBZ 构建的离线训练 Mod，需要现有隔离启动器、Sandboxie 和已验证加载器；当前不是可复制到任意电脑的通用包。

## 在游戏画面里选择 Boss

- Insert：打开或关闭 Boss 工作台。
- ↑ / ↓：选择角色；Enter：确认；Esc 或 F10：关闭。
- 新娘阿花：28 项能力、29 个技能绑定。
- 巨锤客万钧：四项独立能力，默认 F1 重锤攻击、F2 左闪攻击、F3 右闪攻击、F4 左侧攻击。
- 标为“适配中”的角色只能查看状态，尚不能选用。

打开工作台会先恢复主角；切换时回收原角色、训练目标和控制器。装配完成并站稳后按 F6 显式接管。若提示仍在移动，等待主角停稳后再按 F6，无需重启。当前工作台是跟随研究游戏窗口的键盘浮层，不是原生 UMG 或鼠标菜单。

## 操控

F6 接管，WASD 移动，鼠标转向，F7 在存活、敌对且可见的目标间切换，F10 恢复主角。Esc 首次退出接管，再按 Esc 进入游戏原菜单。以画面浮层显示的实际键位为准。

训练使用两个临时目标，保持游戏原生冷却、距离、视线和地形限制。出招被原生状态拒绝时先等收招；目标死亡或被遮挡时，切换到可见的存活目标后再出招。

请在开阔、同层的位置启用，远离悬崖、梯子和狭窄墙角。Boss 原生长位移保留场景限制，可能绕到墙后；这时先按 F10 恢复主角，再用工作台重新选择角色装配。三个落点都不满足导航或视线条件时会安全中止，本版不承诺任意地形可训练。

启动窗口“技能与改键”按所选角色显示动作。修改在下一次启用时生效；不会增加尚未适配的技能。Insert、方向键、Enter 和 Esc 用于工作台。

## 结束

按 F10 恢复，再用启动窗口第 4 步结束。每次接管有固定训练时限，届时自动清理。正式游戏文件和存档不接收研究副本的进度，也不自动回档。

性能优化包括原生对象缓存、输入名称缓存、状态增量读取和相同内容不重绘。测得的游戏线程回调耗时不等于 GPU 帧率。
